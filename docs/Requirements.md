# 投标报价计算器 - 需求文档

## 1. 项目概述
一个专业的投标报价模拟计算工具，支持多种评标模式，帮助用户快速计算投标报价得分及有效性。

## 2. 功能需求

### 2.1 评标模式
- **单低模式**：以最低有效报价为基准计算得分
- **双低模式**：综合最低价和平均价计算得分

### 2.2 参数配置
- **基准价比例**：可自定义基准价计算权重（如：最低价占比、平均价占比）
- **限价设置**：
  - 上限价（超出则废标）
  - 下限价（低于则废标）
- **评分规则**：
  - 基准分值（满分）
  - 上浮扣分系数（每高于基准价1%扣多少分）
  - 下浮扣分系数（每低于基准价1%扣多少分）
  - 最低得分限制

### 2.3 报价管理
- 支持任意添加多家投标报价
- 支持删除/编辑已添加的报价
- 支持清空所有报价

### 2.4 计算结果
- 显示每家报价的有效性状态
- 显示基准价计算结果
- 显示每家报价的偏离率和扣分明细
- 显示每家报价的最终得分
- 支持按得分排序

## 3. 计算逻辑规范

### 3.1 有效性判断
```
如果 报价 > 上限价 → 废标（无效）
如果 报价 < 下限价 → 废标（无效）
否则 → 有效
```

### 3.2 基准价计算

**单低模式**：
```
基准价 = min(所有有效报价)
```

**双低模式**：
```
基准价 = 最低有效价 × 最低价权重 + 平均有效价 × 平均价权重
其中：最低价权重 + 平均价权重 = 100%
```

### 3.3 偏离率计算
```
偏离率 = (报价 - 基准价) / 基准价 × 100%
```
- 正值：报价高于基准价
- 负值：报价低于基准价
- 零值：报价等于基准价

### 3.4 得分计算
```
如果 报价 > 基准价：
    扣分 = 偏离率 × 上浮扣分系数
    
如果 报价 < 基准价：
    扣分 = |偏离率| × 下浮扣分系数
    
如果 报价 = 基准价：
    扣分 = 0

得分 = max(满分 - 扣分, 最低得分)
得分 = min(得分, 满分)  // 确保不超过满分
```

### 3.5 排名规则
1. 有效报价排在无效报价之前
2. 有效报价按得分降序排列
3. 得分相同时，报价低的排名靠前
4. 同分同名次（并列排名）

## 4. 非功能需求

### 4.1 用户体验
- 现代化 UI 设计，参考顶级设计师作品
- 响应式布局，支持桌面和移动设备
- 实时计算，无需手动触发
- 清晰的数据可视化

### 4.2 技术要求
- 纯前端实现，无需后端服务
- Docker 容器化部署
- 跨平台支持（ARM/X86）

## 5. 用户故事

### US-01: 配置评标模式
作为用户，我希望能选择单低或双低评标模式，以适应不同的评标规则。

### US-02: 设置评分参数
作为用户，我希望能自定义基准价比例、限价范围和评分规则，以模拟真实评标场景。

### US-03: 管理投标报价
作为用户，我希望能方便地添加、编辑和删除多家投标报价。

### US-04: 查看计算结果
作为用户，我希望能清晰地看到每家报价的有效性、偏离率、扣分明细和最终得分，并能按得分排序查看排名。

## 6. 默认参数值

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 评标模式 | 单低模式 | - |
| 上限价 | 空（不限制）| - |
| 下限价 | 空（不限制）| - |
| 满分 | 30分 | 价格分满分 |
| 上浮扣分系数 | 1.0 | 每高于基准价1%扣1分 |
| 下浮扣分系数 | 0.5 | 每低于基准价1%扣0.5分 |
| 最低得分 | 0分 | 扣分后的最低分数 |
| 最低价权重 | 40% | 双低模式专用 |
| 平均价权重 | 60% | 双低模式专用 |
