# 投标报价计算器 - 设计规范

## 1. 设计理念
现代、专业、清晰的金融工具类 UI，参考顶级设计师作品风格。

## 2. 色彩系统

### 主色调
- **Primary**: `#6366F1` (Indigo-500) - 主操作色
- **Primary Light**: `#818CF8` (Indigo-400) - 悬停状态
- **Primary Dark**: `#4F46E5` (Indigo-600) - 按下状态

### 语义色
- **Success**: `#10B981` (Emerald-500) - 有效/通过
- **Warning**: `#F59E0B` (Amber-500) - 警告/边界
- **Error**: `#EF4444` (Red-500) - 无效/错误
- **Info**: `#3B82F6` (Blue-500) - 信息提示

### 中性色
- **Background**: `#F8FAFC` (Slate-50) - 页面背景
- **Surface**: `#FFFFFF` - 卡片背景
- **Border**: `#E2E8F0` (Slate-200) - 边框
- **Text Primary**: `#1E293B` (Slate-800) - 主文字
- **Text Secondary**: `#64748B` (Slate-500) - 次要文字

## 3. 字体系统

### 字体族
```css
font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
```

### 字号规范
- **Display**: 36px / 2.25rem - 页面标题
- **H1**: 24px / 1.5rem - 区域标题
- **H2**: 18px / 1.125rem - 卡片标题
- **Body**: 14px / 0.875rem - 正文
- **Small**: 12px / 0.75rem - 辅助文字

### 字重
- **Bold**: 700 - 标题
- **Semibold**: 600 - 强调
- **Medium**: 500 - 按钮
- **Regular**: 400 - 正文

## 4. 间距系统
基于 4px 网格：
- `xs`: 4px
- `sm`: 8px
- `md`: 16px
- `lg`: 24px
- `xl`: 32px
- `2xl`: 48px

## 5. 圆角系统
- **Small**: 6px - 按钮、输入框
- **Medium**: 12px - 卡片
- **Large**: 16px - 模态框

## 6. 阴影系统
```css
/* 卡片阴影 */
shadow-card: 0 1px 3px rgba(0,0,0,0.05), 0 1px 2px rgba(0,0,0,0.1);

/* 悬停阴影 */
shadow-hover: 0 10px 40px rgba(0,0,0,0.1);

/* 弹出层阴影 */
shadow-modal: 0 25px 50px rgba(0,0,0,0.15);
```

## 7. 组件规范

### 7.1 输入框
- 高度: 40px
- 内边距: 12px 16px
- 边框: 1px solid #E2E8F0
- 聚焦: 2px solid #6366F1

### 7.2 按钮
- 高度: 40px (默认) / 36px (小)
- 内边距: 0 20px
- 过渡: all 0.2s ease

### 7.3 卡片
- 内边距: 24px
- 背景: #FFFFFF
- 边框: 1px solid #E2E8F0
- 圆角: 12px

## 8. 布局结构

```
┌─────────────────────────────────────────────────────────┐
│  Header: 标题 + 模式切换                                  │
├─────────────────────────────────────────────────────────┤
│  ┌─────────────────┐  ┌─────────────────────────────┐   │
│  │  配置面板        │  │  报价列表                    │   │
│  │  - 模式选择      │  │  - 添加报价                  │   │
│  │  - 限价设置      │  │  - 报价条目列表              │   │
│  │  - 评分规则      │  │                             │   │
│  └─────────────────┘  └─────────────────────────────┘   │
├─────────────────────────────────────────────────────────┤
│  计算结果区域                                            │
│  - 基准价显示 + 得分排行                                  │
└─────────────────────────────────────────────────────────┘
```

## 9. 动效规范
- **过渡时长**: 200ms (快) / 300ms (标准) / 500ms (慢)
- **缓动函数**: ease-out (进入) / ease-in (退出)
- **数值变化**: 平滑过渡动画
